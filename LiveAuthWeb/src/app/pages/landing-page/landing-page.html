What LiveAuth does

One gate for three common admin jobs.

login

Protect login forms

Add proof-of-work to expensive or suspicious sign-in flows. Real users pass quietly; automated abuse gets priced or slowed down.

api

Gate API endpoints

Issue short-lived JWTs after proof-of-work or Lightning payment, then verify those tokens at the edge of your API.

payments

Meter tool calls

Charge paid MCP or API calls in sats, keep a revenue ledger, and tune usage limits from the dashboard.

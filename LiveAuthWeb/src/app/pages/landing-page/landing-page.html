How LiveAuth Works Under the Hood

Built on proven cryptographic primitives and Bitcoin's Lightning Network.

Proof-of-Work Authentication

  • SHA-256 hash challenges (adjustable difficulty)
  • Client-side solving (no server computation)
  • Replay protection via DB unique constraints
  • Configurable difficulty: 5-30 bits

Lightning Network Integration

  • Direct LND integration (no middleman)
  • Invoice generation on-demand
  • Instant verification on payment
  • Fallback from PoW to Lightning seamless

Security Features

✅ Rate limiting (10/min/IP, 100/min/project) ✅ Replay attack prevention ✅ JWT expiration (configurable TTL) ✅ Project-scoped API keys ✅ Webhook notifications for events
